# UADW v1.0 - Student Package

University Academic Data Warehouse teaching dataset untuk mata kuliah Data Warehouse semester 5.

## Cara menggunakan
1. Mulai dari `09_docs/Modul_Praktikum_01_UADW_v1.0.docx`.
2. Pada Modul 1 gunakan lima master file yang disebutkan di modul dari `01_raw_data/`.
3. Pertahankan source layer apa adanya; jangan melakukan cleansing sebelum instruksi modul meminta.
4. `02_incremental/` digunakan pada tahap incremental ETL/SCD.
5. `04_dirty_scenarios/` digunakan untuk latihan profiling/cleansing terfokus.
6. `07_bug_challenge/` digunakan untuk latihan testing dan debugging.

Semua data adalah sintetis dan dibuat khusus untuk pembelajaran.
