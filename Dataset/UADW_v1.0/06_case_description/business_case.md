# Business Case - Universitas Digital Nusantara (UADW)

Universitas Digital Nusantara memiliki beberapa sumber data operasional: SIAKAD, LMS, dan sistem pembayaran. Pimpinan memerlukan Data Warehouse untuk menganalisis kinerja akademik, tren kelulusan, aktivitas pembelajaran, dan status pembayaran. Data antar-sistem belum sepenuhnya seragam, mengandung duplikasi, missing value, format tanggal campuran, serta perubahan atribut historis.

## Pertanyaan analitik awal
1. Bagaimana tren jumlah mahasiswa aktif per program studi dan angkatan?
2. Bagaimana distribusi dan tren nilai per program studi?
3. Mata kuliah apa yang memiliki tingkat ketidaklulusan tertinggi?
4. Bagaimana perubahan aktivitas LMS berkaitan dengan nilai?
5. Bagaimana tingkat kelulusan tepat waktu?
6. Bagaimana status pembayaran per semester?
7. Bagaimana perubahan profil mahasiswa harus disimpan secara historis?
