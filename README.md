# Data_Warehouse
Mata kuliah Data Warehouse membahas konsep, arsitektur, perancangan, pembangunan, pengelolaan, dan pemanfaatan data warehouse untuk mendukung analisis data dan pengambilan keputusan organisasi. Mahasiswa mempelajari perbedaan sistem transaksional dan analitik, arsitektur data warehouse, dimensional modeling, fact table, dimension table, star schema, snowflake schema, Slowly Changing Dimension (SCD), proses ETL/ELT, data quality, OLAP, analytical query, data mart, serta visualisasi informasi menggunakan perangkat Business Intelligence. Pembelajaran menggunakan pendekatan Outcome Based Education (OBE) dengan kombinasi Student-Centered Learning, Case Method, praktikum, collaborative learning, dan Project-Based Learning. Pada akhir semester mahasiswa secara berkelompok membangun sebuah mini data warehouse mulai dari analisis kebutuhan bisnis, perancangan dimensional model, pembangunan proses ETL, implementasi database, analisis OLAP, hingga dashboard Business Intelligence.
